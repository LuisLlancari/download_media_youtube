Límite del Servidor (render)
Si estás usando esta programa desde GitHub Pages, el servidor tiene recursos limitados: evita descargar archivos muy grandes o videos de larga duración, ya que la descarga podría fallar o tardar mucho tiempo.
Si levantaste el proyecto localmente desde el repositorio, ¡no hay ningún problema! Sin límites.
